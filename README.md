## Описание основного проекта

Проект REST API интернет-магазина, на Django и DRF

### Функционал

### 1. Категории и подкатегории

- **Админка:** создание, редактирование, удаление категорий и подкатегорий.
- **Поля:** наименование, slug, изображение.
- **Связь:** подкатегории привязаны к родительской категории.
- **API:** эндпоинт для просмотра всех категорий с вложенными подкатегориями (с пагинацией).

### 2. Продукты

- **Админка:** добавление, изменение, удаление товаров.
- **Поля:** наименование, slug, категория (через подкатегорию), цена, изображение (с тремя размерами: small, medium,
  large).
- **API:** эндпоинт вывода списка товаров с пагинацией. В каждом товаре отображаются: наименование, slug, категория,
  подкатегория, цена, список изображений.

### 3. Корзина

- **API (только для авторизованных пользователей):**
    - Добавление товара в корзину.
    - Изменение количества товара в корзине.
    - Удаление товара из корзины.
    - Вывод состава корзины с подсчётом количества товаров и общей суммы.
    - Полная очистка корзины.

### 4. Авторизация

- Используется авторизация по JWT-токену (Simple JWT).
- Доступ к операциям с корзиной — только для авторизованных пользователей и только к своей корзине.
- Операции с каталогом (категории, продукты) доступны всем пользователям.

### Технологии

- **Backend:** Django (>=5.2.7), Django REST Framework (>=3.16.1).
- **База данных:** PostgreSQL (через psycopg2).
- **Аутентификация:** drf-simplejwt.
- **Фильтрация и документация:** django-filter, drf-spectacular.
- **Работа с изображениями:** Pillow, django-imagekit.
- **Зависимости:** см. ниже.

### Установка и запуск

1. Клонируйте репозиторий:
    ```
    git clone https://github.com/GGeo-oeGG/GRO_Store
    ```
2. Создайте виртуальное окружение и установите зависимости:

    ```
    dependencies = [
        "django (>=5.2.7,<6.0.0)",
        "requests (>=2.32.3,<3.0.0)",
        "psycopg2-binary (>=2.9.10,<3.0.0)",
        "pillow>=11.2.1,<12.0.0",
        "djangorestframework (>=3.16.1,<4.0.0)",
        "django-filter (>=25.1,<26.0)",
        "drf-spectacular (>=0.28.0,<0.29.0)",
        "django-cors-headers (>=4.7.0,<5.0.0)",
        "environs (>=14.3.0,<15.0.0)",
        "ruff>=0.14.10",
        "uvicorn>=0.38.0",
        "unidecode>=1.4.0",
        "django-imagekit>=6.1.0",
        "djangorestframework-simplejwt>=5.5.1",
    ]
    ```

3. Настройте переменные окружения (переменные указаны в`.env.sample`)
4. Примените миграции:
   ```
   python manage.py makemigrations && python manage.py migrate
   ```
5. Запустите сервер:
   ```
   python manage.py runserver
   ```
6. Создайте суперпользователя:
   ```
   python manage.py createsuperuser
   ```
